## 👨‍💻 About Me

I enjoy turning ideas into practical digital products, building responsive user interfaces, developing reliable backend services, and designing databases that keep application data organized and secure.

- 🔭 **Focus:** Full-stack web development and backend engineering
- 🎓 **Study:** Information Systems, Haramaya University
- 🧰 **Frontend:** HTML, CSS, JavaScript, TypeScript, React, Next.js, Tailwind CSS
- ⚙️ **Backend:** Node.js, Express.js, Python, Django, REST APIs
- 🗄️ **Databases:** MySQL, PostgreSQL, MongoDB
- 🔐 **Engineering interests:** Authentication, role-based access control, secure APIs, Linux, and networking
- 🌱 **Currently improving:** Software architecture, testing, deployment, and production-ready development
- 🤝 **Open to:** Collaboration, learning, and meaningful software projects

> My goal is to build software that is useful, maintainable, accessible, and secure.
